# Folder gambar Infiedu

Logo mark InfiEdu tersedia di `brand/infiedu-mark.png`. Palet yang diambil dari logo dan digunakan pada tema website:

- Navy: `#111B5E`
- Turquoise: `#27D6C5`
- Cyan: `#4CC9DF`
- Coral: `#FF513D`
- Latar muda: `#E9F8FB`

- `brand/`: logo, ikon, dan identitas visual.
- `hero/`: gambar utama atau ilustrasi banner beranda.
- `programs/`: gambar kartu program belajar.
- `facilities/`: gambar fasilitas belajar.
- `testimonials/`: foto siswa atau dokumentasi cerita siswa.
- `tutors/`: foto tutor dan pengajar.

Simpan file gambar pada folder kategori yang sesuai. Untuk menggunakannya di komponen Vue, impor dari `src/assets/images/` agar Vite memproses aset tersebut saat build.
